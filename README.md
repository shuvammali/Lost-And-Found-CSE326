# LPU Lost & Found

A simple Lost and Found website made as a beginner-level college project using HTML, CSS, and JavaScript.

## Features

- Students can report an item they have lost.
- Students can report an item they have found.
- Each report includes the item name, category, location, date, description, and contact information.
- Students can view all reports or filter by Lost and Found.
- Reports are saved in the browser using `localStorage`.

## Technologies Used

- **HTML:** Page structure, semantic sections, links, labels, and form fields.
- **CSS:** Colours, spacing, layout, hover effects, and a small mobile layout rule.
- **JavaScript:** Form submission, event listeners, arrays, objects, filtering, DOM manipulation, and localStorage.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

No installation or server is required.

## Deploy on GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open the repository's **Settings**.
4. Select **Pages** from the left menu.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then click **Save**.
7. Wait for GitHub to publish the website. Your link will appear in the Pages section.

## Important Note

This is a beginner-level demonstration project. Reports are saved only in the browser's local storage. They are not shared between different students, devices, or browsers. Do not enter private or sensitive contact information on a publicly accessible demo website.

## Project Files

- `index.html` - Website structure and report form.
- `style.css` - Website design and responsive styling.
- `script.js` - Form handling and report display.
